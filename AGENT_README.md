# Smart Charging Desk Agent

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Controls a real smart desk built at MHacks 2026. An overhead camera finds the owner's phone and a
motorised wireless charger slides underneath it. The desk also plays the owner's Spotify, runs focus
sessions and only powers the charger when a phone is present.

## What you can ask
- "Play some lofi on my desk" / "skip this song" / "pause the music" / "volume 40"
- "Is my phone charging?" / "Where's my phone?"
- "Park the charger" / "Bring the charger to my phone"
- "Start a 25 minute focus session" / "End focus"
- "How much energy has my desk saved?"

## Input / output
Plain text in (Agent Chat Protocol), a short plain-text reply out. The reply is also spoken aloud at
the desk with ElevenLabs.
